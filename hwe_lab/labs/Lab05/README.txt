Lab 05 Complete Files

According to the Lab 05 PDF, Exercise 01 has no deliverables.
Only Exercise 02 and Exercise 03 require FPGA files.

Exercise 02: 4-bit Adder/Subtractor
Files:
- ex02_adder_subtractor/Adder_Subtractor.vhd
- ex02_adder_subtractor/Adder_Subtractor.xdc

Usage:
- SW3..SW0 = A
- SW7..SW4 = B
- SW8 = mode, 0 for addition, 1 for subtraction
- LED3..LED0 = 4-bit result
- LED4 = carry for addition or borrow flag for subtraction

Exercise 03: 4-bit BCD Adder
Files:
- ex03_bcd_adder/BCD_Adder.vhd
- ex03_bcd_adder/BCD_Adder.xdc

Usage:
- SW3..SW0 = BCD input A, valid range 0 to 9
- SW7..SW4 = BCD input B, valid range 0 to 9
- rightmost 7-segment digit shows the result digit
- LED0 shows carry

Important:
The PDF asks for .xdc and .bit deliverables.
The .bit file must be generated by Vivado after adding the VHDL and XDC files, running synthesis, implementation, and Generate Bitstream.
